# mounted-officer 제작 브리프

- 독립 저장소 모드로 수행. 사용자 지정 이름 없음; 신원을 추정하지 않음.
- 원본: 최신 첨부 Image #1 기마 무장 ukiyo-e. 실제 이미지 컨텍스트 확인.
- 스타일: 최신 첨부 Image #2 검은 갑옷 인물 회화. 실제 이미지 컨텍스트 확인.
- 두 입력의 파일 바이트는 호스트 미제공: actual_file_saved=false, SHA-256=unknown. 외부 임시 원본 접근 금지. 재생성한 그림을 입력 사본으로 표시하지 않는다.
- 원본 보존: 길고 성숙한 얼굴, 뚜렷한 코, 검은 콧수염과 긴 턱수염. 높고 검은 투구, 붉은 원 문양 및 붉은 장식. 파랑 끈 검정 판갑, 붉은 하단 매듭, 녹색 장식 소매와 흰 허리띠.
- 스타일 적용: 회화적 입체 명암, 금속의 날카로운 국소 반사, 직물의 낮은 광택, 얼굴 중심의 묘사. 스타일 초승달·얼굴갑옷·얼굴 복사 금지.
- 기본 투명 상반신 한 명, 말·문자·풍경 제외. 손은 자연스럽게 허리 쪽으로 내림. 원본 기마 자세에서 상반신 UI 구도로 조정한 부분은 추정/연출.
- 목표 2048×3072, 실제 도구 출력 별도 검증. 최대 3후보.
