# 20종 입력 등록부

[catalog.json](catalog.json)은 2026-09-22 사용자 제공 `해신이미지자산목록.pdf`(기준 commit `c3293ba`)와 해당 세션의 실제 프로젝트 PNG로 확인한 제작 명세다. 경로·해시는 출처 대응을 위한 값이며 자료 접근 허가가 아니다. PDF 사본이나 이미지를 스킬에 포함하지 않는다.

## 원본 확인

- `source.path`는 프로젝트 루트 기준 출처, `source.sha256`은 확인 당시 파일 전체 해시다. 실제 도구에는 허용 영역의 `staged_path`를 사용한다. 반입 경로·파일 해시를 실행 기록에 추가한다.
- 반입 해시가 기준과 다르면 다른 유닛·다른 버전인지 먼저 확인한다. 사용자가 최신 원본으로 지정했으면 변경 사유와 새 해시를 실행 기준으로 고정하고 기존 이력을 보존한다. 파일명만 같다는 이유로 이전 승인을 승계하지 않는다.
- `atlas_region`은 픽셀 단위 `[x,y,width,height]`다. 허용 영역의 원본에서 해당 사각형을 손실 없이 분리하며 알파·색을 보존하고 원본 해시, 좌표, 출력 크기·해시를 기록한다. 분리는 이미지 재디자인이 아니다. 범위 밖 좌표나 이미지 크기 불일치는 입력 오류다.
- `preserve`는 초기 관찰 항목이지 미확인 구조의 정답이 아니다. 실제 이미지를 열어 부품 수·비대칭·불명확한 면을 브리프에 확정한다. 괴수의 가려진 팔을 임의로 복제하지 않는다.
- 공통 스타일은 `_workspace/shared/style/source/wanderburg_style_ref.png`의 등록 상태를 확인한다. 디자인 이미지의 사실성과 스타일 이미지의 단순화를 역할별로 분리한다.

## 대응과 예외

- `asset_id`는 현재 2D 텍스처 키를 유지한다. 보스 역할 `broadside`는 `boss-fire`, `final`은 `flagship`이다. `boss` 대체 실루엣을 21번째 유닛으로 추가하지 않는다.
- `player`는 거북선이다. 현재 3D의 `player_command_ship`은 판옥선이므로 동일 자산으로 자동 대응하지 않는다. `support`와의 재사용도 원본·구조·승인 버전을 실제 비교한 뒤 기록한다.
- 조총선 `arquebus`의 원본에는 병사 4명이 있으나 이번 3D 명세는 병사를 제외한다. 이 변경은 관찰 사실과 별도로 `user_override`에 유지한다.
- 괴수는 아군 고래·크라켄·거대오징어 3종이다. 코드의 진영 표식·파문·부상/잠수 연출은 모델의 부속지나 지오메트리로 구워 넣지 않는다.
- 기존 shared 검수 게시본은 보조 입력으로 사용한다. 고바야부네의 `changes_requested` 최종 보관본, 세키부네의 미승인 멀티뷰, 아타케부네의 런타임 미검증 모델은 각 상태를 보존한다. 과거 사용자의 결함 완화는 해당 자산·버전에만 적용한다.

## 재사용할 제작 경험

세키부네의 높은 정면 카메라·비대칭 고리 재발은 멀티뷰 교차 검수 항목으로, 아타케부네의 노·깃발·돛 반대면 보정은 국소 수정 절차로 반영한다. 특정 함선의 노 수·회전각·스케일·면 수는 다른 유닛의 기본값으로 복사하지 않는다. 실제 비교 자료가 필요하면 제작자의 shared 게시 사본으로 전달한다.
