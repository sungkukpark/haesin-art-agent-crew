# 인물 초상 생성 프롬프트

실제 두 이미지를 본 뒤 중괄호를 관찰 내용으로 채우고 사용하지 않는 선택 항목은 지운다. 추가 지시가 없으면 기본값만으로 완성한다. 아래 크기·품질 표현은 도구의 전용 API 인자가 아닌 프롬프트 목표다.

```text
게임 UI와 필살기에서 공용으로 쓸 단일 인물의 고해상도 상반신 초상을 제작한다.

이미지 1 — 인물 원본: {subject_reference}
이 인물의 {얼굴형, 눈·코·입의 관계, 연령감, 헤어·수염, 피부색, 고유 특징}을 유지한다.
원본에서 확인한 복식은 {관찰 내용}이며, 보이지 않는 부분은 이를 자연스럽게 연장한다.

이미지 2 — 스타일 참조: {style_reference}
{실제로 관찰한 붓질, 피부·금속·직물의 재질 차이, 명암, 색채, 디테일 밀도}를 적용한다.
참조 인물의 얼굴이나 고유 의상·문양·무기·말을 복제하지 않는다.
반실사 역사 인물 일러스트로, 얼굴의 입체감과 눈빛을 선명하게 하고 세부 묘사는 얼굴을 중심으로 배분한다.

구도: 한 인물만, 머리 장식부터 허리 위까지. 자연스러운 약한 3/4 방향, 차분하고 자신 있는 표정.
얼굴과 어깨를 중앙 가까이 배치하고 얼굴 아이콘 크롭에 여유를 둔다.
머리 장식·어깨·보이는 손의 실루엣에 충분한 여백을 두며 의도 없이 잘리지 않게 한다.
배경: 실제 투명 알파. UI 프레임, 글자, 로고, 워터마크, 다른 인물, 말, 풍경, 필살기 이펙트 없음.
출력 목표: 세로 2048×3072의 고해상도 마스터 한 장. 작은 원본을 단순 확대하지 말고 피부·직물·금속을 새로 묘사한다.

추가 지시: {additional_prompt — 있을 때만}
추가 지시로 명시한 변경 외에는 인물 정체성을 유지한다.
```

수정 시에는 원래 두 이미지에 더해 `previous_result`를 편집 대상으로 구분하고 다음을 덧붙인다.

```text
편집 대상: {previous_result와 버전}
그대로 유지: {승인된 얼굴·복식·구도·색채 등}
이번에 변경: {사용자 지시 또는 디렉터의 필수 수정}
직전 피드백 충족 기준: {실제 관찰 가능한 기준}
```
