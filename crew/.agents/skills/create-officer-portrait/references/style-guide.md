# RTK14 참조 기반 portrait 스타일 가이드

## 분석 근거와 사용법

2026-10-03에 [공식 무장 페이지](https://www.koeitecmoamerica.com/rtk14/characters.html)의 게시 인물 62명 전체를 수집했다. 목록 JPG 62개와 상세 PNG 62개, 누락 0, 상세 PNG 해시 중복 0이다. PNG 원본은 모두 640×854이며 실제 투명 알파가 있다. 게임에 수록된 1,000명 이상의 전체 이미지나 2K 원본을 확보했다는 의미가 아니다.

메인과 art-director는 6장의 연락시트로 전체 62명을 관찰했다. 디렉터가 원본 픽셀로 별도 확인한 14명은 `teifu`, `kakuka`, `chousen`, `kouchu`, `ryuzen`, `choukou`, `sousou`, `choukaku`, `soukyu`, `souchu`, `kyocho`, `shukuyu`, `ougenki`, `ryofu`다. 나머지 48명을 원본 픽셀 수준으로 개별 검수했다고 보고하지 않는다.

로컬 원본·수집 기록은 coordinator의 `references/rtk14/`에 보존된다. 다른 역할은 coordinator 폴더를 열지 않고 아래 shared 사본을 사용한다. 경로는 저장소 기준이며 Git에서 제외된 로컬 자료이므로 다른 clone에 없을 수 있다.

- 이미지 묶음: `_workspace/shared/review-inputs/rtk14-portraits-20261003-v001/coordinator/` — `manifest.json`, `portrait/image_<id>.png`, `contact-sheets/sheet-01.jpg`~`sheet-06.jpg`, `handoff.json`.
- 독립 분석: `_workspace/shared/review-inputs/rtk14-style-analysis-20261003-v001/art-director/` — `style-analysis.md`, `evidence.json`, `handoff.json`.
- 독립 분석 문서 SHA-256: `bfcf063ae9468e4171c7709b1cb13eb27c1ee0e8628d07851b9f795db781bcd1`.

독립 판정 `approved_for_next_stage`는 이 가이드 작성 근거에 대한 판단이다. 새 portrait나 게임 적용의 승인이 아니다. 원본 이미지는 스타일 연구용 로컬 참조이며 스킬 패키지나 런타임 자산에 복제하지 않는다.

생성 시에는 사용자가 지정한 **스타일 이미지 한 장**의 실제 특징을 우선 관찰한다. 전체 자료를 매번 모델에 넣거나 특정 인물을 자동 선택하지 않는다. 사용자가 선택을 맡긴 경우에만 표현 유형에 맞는 한 장을 골라 경로·해시와 이유를 기록한다. 이 텍스트만으로 필수 스타일 이미지를 대체하지 않는다.

## 인물별 차이를 보존할 것

- 노장 `teifu`, `kouchu`: 주름·수염·금속 마모가 인물성을 만든다. 사진의 나이를 지우지 않는다.
- 청년 `kakuka`, `souchu`: 깨끗한 중간톤과 상대적으로 가벼운 얼굴 명암. 젊음을 모든 인물의 기본값으로 삼지 않는다.
- 둥근 체형 `ryuzen`, 넓은 목·턱의 `kyocho`: 얼굴과 몸의 개성을 날씬한 영웅 체형으로 획일화하지 않는다.
- 장식적인 `chousen`, `ougenki`와 무장한 `shukuyu`: 부드러운 피부·비단 또는 금속·어깨 회전의 차이를 유지한다. 성별만으로 부드러움·노출·체형을 결정하지 않는다.
- 문관 `choukou`, `kakuka`: 관모·소매·손짓으로도 충분히 역할이 읽힌다. 모든 제독·무장에 칼과 갑옷을 추가하지 않는다.

## 공용 마스터로 옮길 때의 조정

수집 원본에는 기마(`soukyu`), 큰 손 원근(`sousou`), 마술광(`choukaku`), 과감한 프레임 절단이 있다. 이 요소를 스타일의 필수 조건으로 일반화하지 않는다. 기본 생성은 한 인물의 투명 상반신이며 말·다인·불티·마술광·장면은 요청할 때만 추가한다.

원본 일부의 잘린 장식이나 무기를 그대로 재현하지 않고 머리·어깨·보이는 손에 여백을 확보한다. 새 마스터 목표는 2:3 세로 2048×3072다. 이는 640×854 수집 원본의 확대 납품이 아닌 새 생성 목표다. 실제 크기와 품질을 검증하고 목표 미달은 별도 기록한다.

인물 원본 사진이 정체성을, 선택 스타일 이미지가 표현을 결정한다. 스타일 참조 속 RTK14 인물의 얼굴·특정 투구·문양의 이식이나 시대·국적 변경을 스타일 적용으로 간주하지 않는다. 사용자가 RTK14 초상 자체를 인물 원본으로 지정한 경우에는 그 원본의 얼굴·복식을 보존한다. 추가 프롬프트에 복식 변경이 있으면 그 범위만 바꾸며 관찰과 추정을 구별한다.

검수 우선순위는 얼굴 정체성·해부학·알파·잘림 → 얼굴 크롭 가독성·재질·추가 지시 반영 → 미세 색조·붓질 취향이다. 128/256픽셀 미리보기와 밝고 어두운 배경에서의 경계를 확인하되 실제 게임 통합 검증으로 보고하지 않는다.
