# HAESIN 과제 제출용 아트 crew 실행 범위

이 폴더는 원래 해신 아트 crew 지침의 독립 실행용 부분 묶음이다. 문서 열람·채점 요청은 새 아트 제작 요청이 아니다.
원래 에이전트·스킬 정의는 바이트 동일 사본이며 이 문서는 제출용 입력과 실행 경로를 고정한다.

- 메인 coordinator는 이 `crew/` 폴더를 작업 루트로 고정하고 `_workspace/AGENTS.md`와 `_workspace/shared/agent-workflow.md`를 따른다. 다른 원래 게임 저장소를 검색하지 않는다.
- 대표 실행은 coordinator → character-concept-artist → art-director의 3개 독립 에이전트 협업이다. Portrait 실행은 가운데 역할만 portrait-artist로 바꾼다. 나머지 역할은 대체 자산 경로다.
- 이 제출 실행에서는 메인이 제작 역할을 대신하는 fallback을 사용하지 않는다. 호스트에 필요한 역할이 없다면 로딩 미완료로 종료하고 실행 성공으로 보고하지 않는다.
- coordinator는 입력 역할·해시·범위·예산을 고정하고 실제 specialist 호출을 수행한다. specialist가 설계·프롬프트·자기 검수와 후보 인계를 담당하고 art-director가 제작 전 협의·후보 독립 검수를 담당한다. coordinator는 모델 서비스와 최종 납품·해시 대조를 담당한다.
- 실제 응답에서 얻은 역할 식별자·버전·해시·판정만 기록한다. director 승인 없이 다음 단계로 넘기지 않고, 요청한 기술 검증 없이 package 완료를 기록하지 않는다. 작업 기록을 가상으로 만들지 않는다.
- 제공 scout 원본과 등록 스타일은 shared 사본을 쓴다. 재실행 결과는 새 batch_id와 미사용 버전으로 저장하며 examples/evidence의 과거 결과를 덮어쓰지 않는다.
- 사용자가 컨셉만 요청하면 모델 서비스를 호출하지 않는다. 모델·패키지 재실행은 Tripo 접근과 사용자가 정한 모델 횟수·크레딧 예산이 있을 때만 수행한다.
- 호스트의 imagegen 지침·image_gen·에이전트 위임 기능은 환경 의존성이다. 이 폴더는 별도의 모사 에이전트나 Node runner를 만들지 않는다.
- 독립 저장소 모드로 수행한다. 원래 게임 런타임 수정·커밋·원격 게시를 자동 실행하지 않는다.
